# 批量文件改名助手 1.2

面向 Windows 10/11 64 位的 C# WinForms 便携软件。离线运行，已包含 .NET 运行库，最终用户无需安装开发环境。

## 下载和使用

在 [Releases 下载页](https://github.com/188yyds/bulk-file-renamer/releases) 下载 EXE、源码 ZIP、使用说明和测试报告。GitHub 会清理中文附件名，因此下载名称使用英文，内容仍为中文：

- `BatchFileRenamer-win-x64.exe`：批量文件改名助手.exe
- `BatchFileRenamer-Source-v1.2.0.zip`：批量文件改名助手_源码.zip
- `UserGuide.txt`：使用说明.txt
- `TestReport.txt`：测试报告.txt

仓库为私有，下载时需要登录拥有访问权限的 GitHub 账号。

先选择源目录、文件通配符和筛选条件，设置一条改名规则，再扫描预览。只有勾选且状态合法的文件才能执行。界面包含“命名规则与试算”“环境与安全自检”“导出预览清单”和“最近批次详情”。

例如：`*.h5`；字段 `U` 范围 `3.5` 到 `4.5`，包含边界；把 `nsweep` 设置为 `100`。

## 文件安全

软件不解析或编辑文件内容，只按原始字节校验完整性。支持原地改名、移动和复制；预览不修改文件；批内重名禁止执行；覆盖默认关闭，旧目标先移入相邻批次备份目录。

复制先写入唯一临时文件，核对长度和 SHA-256 后提交。移动和撤销也经过完整性校验。数据清理调用 Windows 回收站，回收失败保留文件并提示。备份不自动删除。

## 测试结果及边界

1.2 版实际执行了 87 项测试：**85 PASS、0 FAIL、2 SKIP**。全部使用新建模拟文件，没有操作用户原始数据。

测试环境为 Linux。原生 Windows 回收站和 NTFS 专项明确跳过，Windows GUI、启动、ACL 和实际 NTFS 等仍未实机验证。编译成功不等于全部 Windows 环境验收通过。详细结果见 [测试报告.txt](测试报告.txt) 和 [测试原始结果.json](测试原始结果.json)。

## 源码和维护

- `Renamer.App`：中文 WinForms 界面、Windows 回收站适配器。
- `Renamer.Core`：规则、预览、安全批次、撤销与恢复。
- `Renamer.Tests`：只使用模拟文件的回归测试。
- `构建.cmd`、`测试.cmd`：维护者的构建和测试入口。

维护者需要 .NET 8 SDK；最终用户直接运行发布的 EXE。更多实现说明见 [README_CN.md](README_CN.md)，软件使用说明见 [使用说明.txt](使用说明.txt)。
